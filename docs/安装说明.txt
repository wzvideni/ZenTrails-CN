Zen Trails 简体中文汉化补丁 v1.0
==================================

游戏：Zen Trails（Steam）
游戏引擎：Unity 2019.1.8f1（Mono）
汉化方式：BepInEx 5 + XUnity.AutoTranslator + 内置静态词典（不联网、不发请求、不修改游戏本体文件）

一、这个补丁做了什么
--------------------
1. 界面文本：主菜单、教程、设置、按键绑定、编辑器所有面板、修改面板、
   新线段默认设置、背景、自动暂停、保存/读取、作品上传、社区中心全部译成简体中文。
2. 字体：中文字形来自游戏根目录的 arialuni_sdf_u2019（TMP 字体资源包），
   通过 AutoTranslator 的 FallbackFontTextMeshPro 自动回退，不需要重打图集。
3. 术语统一，例如：线段 / 根线段 / 轨迹 / 轨迹宽度 / 辉光 / 风车化 / 螺旋化 /
   收缩化 / 细分 / 递归复制 / 微移 / 色板 / 渐变 / 李萨如曲线 / 万花尺 / 飘带 /
   手风琴 / 社区中心 / 图案（作品）。
4. 语气保持原作的轻松、俏皮、自嘲。
5. 界面微调：线段信息气泡「更多」里的「粗细 / 辉光 / 图层顺序」三行，
   原文是按英文词长排的，中文下会参差不齐（辉光向里缩、图层顺序的数值框
   偏右一格）。随包的 ZenTrailsCN.dll 会把这三个标签右对齐、三个数值框
   对齐到同一列，效果和英文原版一致。

二、安装
--------
1. 完全退出游戏（含后台进程）。
2. 把压缩包里的所有内容解压到游戏根目录，覆盖同名文件：
       ...\Steam\steamapps\common\Zen Trails\
   解压后应当看到：
       Zen Trails.exe
       winhttp.dll              ← BepInEx 加载器
       doorstop_config.ini
       .doorstop_version
       arialuni_sdf_u2019       ← 中文字体资源（约 30MB，别删）
       BepInEx\
           core\                ← BepInEx 本体
           plugins\             ← XUnity.AutoTranslator
                          + ZenTrailsCN.dll（界面微调：标签右对齐，几 KB）
           config\AutoTranslatorConfig.ini
           Translation\zh-CN\Text\
               zhuanti.txt      ← 主词典（437 条）
               zh_extra.txt     ← 补充词典（图案预设名等 56 条）
               zz_regex.txt     ← 动态数字/数值类文本的正则条目
3. 启动游戏即可，界面即为中文。

三、卸载 / 还原
--------------
删掉上面列出的这些文件和 BepInEx 文件夹即可；
或者在 Steam 里「验证游戏文件的完整性」，游戏会恢复成英文原版。

四、想自己改词 / 加词
--------------------
词典是纯文本，UTF-8，一行一条：英文=中文
    BepInEx\Translation\zh-CN\Text\zhuanti.txt
注意：
  1. 键（等号左边）必须和游戏里的英文原文完全一致，大小写、空格、换行都要对。
  2. 换行写成 \n（两个字符）。
  3. 只含数字/名字的动态文本用 zz_regex.txt 的 r:"正则"=译文 形式。
  4. 词典只在游戏启动时读取一次，改完要重启游戏才生效。

五、已知情况（不影响游玩）
------------------------
1. 按键绑定面板里的按键名保持英文（Space、Tab、MiddleMouse、UpArrow、Control + Z 等），
   这是键盘上的实际按键标识，保留英文更好认。其中 Space 显示为「空格」。
2. 社区中心里别人上传的作品标题、作者名不翻译（那是玩家自己写的内容）。
   未登录 Steam 时作者显示为「[未知]」。
3. 极少数由代码拼接的数字型文本（如页数、条目数）用正则处理；
   如果以后游戏更新改了措辞，这类文本可能重新露出英文。
4. 左上角 ZEN TRAILS 水印是品牌 logo，保留英文。
5. 一小段上传提示里的空格会被那一个 Text 组件吃掉（例如「上传到Steam创意工坊」），
   属于游戏本身的排版怪癖，文字内容完整。

六、文件校验
-----------
